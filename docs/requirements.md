# Kakeibo 要件定義書

## アプリの目的

個人の収支・残高を管理する家計簿アプリ。いつ・どの口座から・いくら入出金したかを記録・可視化する。将来的にグループ（同一生計者）の割り勘管理にも対応する。

---

## フェーズ構成

| フェーズ | 内容 |
|---------|------|
| **フェーズ1（今回）** | 個人機能：ログイン・カレンダー・入出金管理・口座管理 |
| フェーズ2（後日） | グループ機能：メンバー管理・割り勘・共有家計簿 |

---

## フェーズ1 機能要件

### 1. 認証機能（Spring Security）

- ユーザー登録（ID・パスワード・表示名）
- ログイン / ログアウト
- ログイン中のユーザーIDを画面に常時表示
- 自分のデータのみ表示・操作できる（他ユーザーのデータにアクセス不可）

---

### 2. トップ画面（月間カレンダー）

**表示内容：**

- ログインユーザーID / 表示名
- 現在の**総残高**（全口座の合算）
- **月間カレンダー**（7列 × 5行）
  - 各日付に：その日の収入・支出・収支を表示
  - 土曜・日曜は色分け
- 月の切り替えボタン（前月・翌月）

**操作：**

- 日付をクリック → その日の入出金入力画面へ

---

### 3. 入出金入力画面

**入力項目：**

| 項目 | 内容 |
|------|------|
| 日付 | 必須。カレンダーからの遷移時は自動セット |
| カテゴリ | 必須。例：食費・家賃・光熱費・給料・その他（マスタ管理） |
| 収支タイプ | 必須。収入 / 支出 |
| 金額 | 必須。1円以上の整数 |
| 口座 | 必須。登録済み口座から選択（マスタ） |
| 備考 | 任意。最大100文字 |

**機能：**

- 入力後に一覧画面（その日の取引）へ戻る
- バリデーションエラーはフォーム上に表示

---

### 4. 取引一覧・編集・削除

- 日付フィルタで絞り込み表示
- 各取引の編集・削除が可能
- 一覧表示列：日付・カテゴリ・収支タイプ・金額・口座・備考

---

### 5. 口座マスタ管理

- 口座の登録・編集・削除（画面）
- 登録項目：口座名・初期残高
- 口座別残高を自動計算（初期残高 ± 取引金額の合算）
- トップ画面の「総残高」は全口座残高の合算

---

### 6. 月間サマリー

- 指定月の収入合計・支出合計・収支を表示
- 口座別の残高一覧も表示

---

## データモデル（フェーズ1）

```sql
User
  - id (PK)
  - username (unique)
  - password (hashed)
  - displayName

Account（口座マスタ）
  - id (PK)
  - user_id (FK → User)
  - name（例：現金、楽天銀行）
  - initialBalance（初期残高）

Transaction（取引）
  - id (PK)
  - user_id (FK → User)
  - account_id (FK → Account)
  - date
  - amount
  - category (Enum)
  - type (INCOME / EXPENSE)
  - memo（最大100文字）
```

---

## 画面遷移

```
ログイン画面
    ↓
トップ（月間カレンダー＋総残高）
    ├─ 日付クリック → 入出金入力画面 → 取引一覧
    ├─ 取引一覧 → 編集画面 / 削除
    ├─ 月間サマリー画面
    └─ 口座管理画面（登録・編集・削除）
```

---

## 実装順序（フェーズ1）

1. プロジェクト構造を Gradle + PostgreSQL + React に再作成
2. `docker-compose.yml` で PostgreSQL 起動
3. Spring Security + `User` エンティティ + ログイン API
4. `Account`（口座）エンティティ・CRUD API
5. `Transaction` エンティティ（userId/accountId付き）・CRUD API
6. カレンダー集計 API（月別・日別）
7. React フロントエンド：ログイン画面
8. React フロントエンド：トップ（月間カレンダー＋総残高）
9. React フロントエンド：入出金入力・一覧・編集
10. React フロントエンド：口座管理・月間サマリー
11. 動作確認・テスト

---

## 検証方法

- `docker compose up -d` で PostgreSQL 起動
- `./gradlew bootRun` でバックエンド起動
- `cd frontend && npm run dev` でフロントエンド起動
- ブラウザで React アプリにアクセス
- ログイン → カレンダー表示 → 日付クリック → 入出金登録 → カレンダーに反映されることを確認
- 口座マスタ登録 → 残高がトップ画面に反映されることを確認
